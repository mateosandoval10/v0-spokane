# GSCG x USL Spokane

Static GitHub Pages deliverable hub for the Gonzaga Sport Consulting Group's Spring 2026 sponsorship activation work with USL Spokane.

Pages:
- `index.html` - concise landing page
- `activations.html` - activation strategy and why-fit explanations
- `work.html` - uploaded work previews and week-by-week explanations
- `decks.html` - final deck and sponsor pitch deck previews

## Local Preview

Run a static server from this folder:

```bash
python3 -m http.server 4321
```

Then open `http://localhost:4321`.

## GitHub Pages

This site is intentionally build-free. Publish the repository from the `main` branch `/docs` folder in GitHub Pages settings.

The `docs/` folder is the GitHub Pages section. It contains a complete static copy of the site:
- `docs/index.html`
- `docs/activations.html`
- `docs/work.html`
- `docs/decks.html`
- `docs/assets/`
